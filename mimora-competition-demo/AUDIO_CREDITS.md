- Licence shown on the source page: **CC0 / Public Domain**

The site starts the background track only after the visitor explicitly turns music on. The footer displays a provenance credit. If the external track cannot be loaded, the demo falls back to a short cheerful melody synthesized locally with the Web Audio API.
